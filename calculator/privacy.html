Privacy Policy

Last updated: 9 November 2026

This policy explains how Friendly Calculator handles information when you visit this website, submit an enquiry or use an approved API integration.

Calculator data

Calculator inputs and calculations on the main website are processed in your browser. These browser calculators are not designed to transmit the values you enter to Friendly Calculator servers.

Contact, advertising and API enquiry forms

When you submit a form, the information you provide is transmitted securely to our backend and stored so that we can review and respond to your enquiry. Depending on the form, this may include your name, email address, company or project name, optional phone or budget details, enquiry type and message. Enquiries are accessible only to authorised administrators.

We use a hashed connection identifier to help prevent repeated automated submissions. It is not stored as a plain IP address. Older rate-limit entries are cleaned during subsequent form submissions, targeting a 48-hour window.

Please do not include passwords, OTPs, API secrets, payment-card details, government identity numbers or other sensitive information in an enquiry.

API credentials and usage

For approved API access, Friendly Calculator stores a cryptographic hash and short prefix of each API key, not the original secret key. The original key is shown only once when created. API usage records may include the key identifier, calculator endpoint, response status and timestamp; request payloads are not stored for usage analytics. Usage records are routinely cleaned when API requests occur, targeting a 90-day retention window.

API keys are intended for server-side use. Keep them confidential and contact us promptly if a key may have been exposed.

Hosting and data processors

The source code is maintained on GitHub. The hosting provider for a live deployment may be GitHub Pages or another configured hosting provider. Enquiry storage, authentication and API processing use Supabase. The Supabase project is configured in the ap-northeast-2 region (Seoul, South Korea). These providers process information to operate the service under their own terms and privacy policies.

Optional email updates

If an optional newsletter or email resource is introduced, marketing messages will be sent only where you have separately opted in. Submitting a general enquiry does not automatically subscribe you. Each marketing email will provide an unsubscribe method, and you may withdraw consent. Newsletter signup is not currently represented as an active feature unless a signup form is explicitly displayed on the website.

Affiliate links, referrals and sponsored placements

If approved affiliate links, sponsored placements or referral partnerships are introduced, they will be identified clearly. Clicking an affiliate link may allow the partner to record that a referral came from this website using cookies or similar technologies. Any personal information you provide to a partner is handled under that partner's privacy policy. We do not sell visitors' personal data as lists, and we do not share enquiry details with a referral partner unless you explicitly ask us to make an introduction or otherwise consent.

Advertising and cookies

This website includes Google AdSense publisher code. Ads will be served only if Google enables them for this website and publisher account. If advertising is served, Google and its partners may use cookies or similar technologies for ad delivery, measurement and personalisation, subject to Google's policies and the choices available in your region. The presence of code does not confirm approval or active ad serving.

Review Google's advertising technologies and Google's Privacy Policy.

Professional introductions and optional lead sharing

If a visitor requests an introduction to a service provider, the website will explain the provider category and information to be shared and ask for explicit consent before sharing. Only necessary information should be collected. Sensitive financial credentials, identity documents and health records must not be submitted through general enquiry forms. No contact list is sold.

Newsletter and email preferences

If an optional newsletter or email resource is introduced, it will require a clear opt-in. We will state the purpose and expected frequency, provide an unsubscribe method, and use the address only for the selected communication. Email signup is not currently active.

Retention and privacy requests

Enquiry records are retained while needed to respond, maintain business records, prevent abuse or meet applicable obligations. You may request access, correction or deletion of an enquiry by emailing avnishahirwar415@gmail.com. We may need to retain limited records where required for security, legal or legitimate operational reasons.

External links

Links to Instagram, Facebook, LinkedIn and other external websites are governed by those providers' own privacy practices. Friendly Calculator does not control their services.

Changes

This policy may be updated when website features or legal requirements change. The latest version will be published here.

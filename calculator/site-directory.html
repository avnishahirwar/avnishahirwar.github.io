Find the right tool quickly

For a quick arithmetic operation, start with the Basic Calculator. For an invoice or product price, use GST or Discount. For borrowing, use Loan EMI; for savings illustrations, use FD, Savings Interest, EPF or SIP. For household planning, use Electricity, Fuel or Inflation. For payroll and business estimates, use Salary, Income Tax, TDS or Profit & Loss.

How to use a calculator responsibly

  1. Open the relevant tool and read the input labels before entering values.
  2. Use the same units and time period requested by the calculator.
  3. Review the formula, worked example and assumptions on the tool page.
  4. Compare important tax, finance or utility results with the relevant official source or provider.

Each tool page links back to the calculator directory and the methodology page, so visitors can move between tools and understand the assumptions behind an estimate.

Calculator outputs are estimates for general information. Check official sources and qualified professionals for decisions involving tax, finance, health or legal obligations.

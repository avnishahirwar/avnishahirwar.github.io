Integration path

  1. Review the supported calculators and input contracts.
  2. Create a customer account and API key in the dashboard.
  3. Keep the private key on your server, then send a test request.
  4. Use the embed builder when a public browser calculator is sufficient.

Important: API availability is a separate, smaller set than the full public calculator catalogue. Validate the calculator and inputs against the API documentation before building a production integration.

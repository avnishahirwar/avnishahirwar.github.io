Languages & Page Coverage

Friendly Calculator is building a multilingual calculator library. Choose a language from the header on any page. When a translated copy of a specific page is not available yet, the site keeps you on that same page in English and shows the selected-language navigation instead of sending you to a different homepage.

Important: “All languages” cannot mean every language spoken worldwide without a translation team for each language. The current site supports the language editions below and has a safe same-page fallback for every other public page. We will expand page-by-page coverage rather than publish misleading machine translations.

How same-page fallback works

  1. Select a language in the header.
  2. If the translated URL exists, you open that translated page.
  3. If it does not exist, the equivalent English page opens with selected-language navigation and a clear availability notice.
  4. The calculator still works, and you can return to a translated page through the language selector at any time.

Translation and correction policy

Translated pages should preserve the original formula, units, assumptions, safety notices and source links. A translation is not allowed to change a financial, tax, health or legal conclusion. If you find a wrong translation or a missing high-value page, please send the URL through the contact page. See the editorial policy and calculation methodology.

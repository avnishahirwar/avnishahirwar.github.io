3. What you get

Responsive display

Use a 100% width iframe so it can fit the content column of your page.

No API key

The basic embed works through a public calculator page; there is no API credential to configure.

No calculation backend for you

Your website only displays the calculator frame. You do not need to build or host the calculator logic.

Attribution

Keep the Friendly Calculator attribution visible in the embed experience and do not misrepresent the calculator as your own product.

4. Compatibility and privacy

  • Use an HTML or custom-code block that allows iframe embeds.
  • Some hosted website builders restrict iframes; check your platform's embed settings.
  • Set a suitable height and test on mobile and desktop.
  • The embedded calculator is served from Friendly Calculator. Your site does not need to receive calculation inputs.
  • Do not use calculator results as a substitute for professional financial, tax, legal or medical advice.
Fair use: Free availability is subject to reasonable use, service availability and the site's published terms. This is not an unlimited uptime or traffic guarantee.

5. Need direct JavaScript or a public API?

The current free integration is an iframe embed. A documented public JavaScript SDK or remote API is not being advertised as available yet. We will publish one only after its formulas, versioning, limits, security and support expectations are tested.

Frequently asked questions

Is the calculator embed free?

The basic public iframe embed is offered without an API key or separate setup charge. Normal hosting and service availability limits still apply.

Do I need to install a plugin?

No plugin is required if your website editor supports custom HTML or iframe blocks.

Can I change the calculator's formula?

No. The embedded calculator uses the calculator and formula maintained by Friendly Calculator.

Can I remove the Friendly Calculator attribution?

Please keep the attribution intact. It identifies the provider and helps visitors find the original calculator.

Is a public API available?

Not currently advertised. Use the iframe builder until a separately documented API is released.

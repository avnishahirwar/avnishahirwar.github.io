Perguntas frequentes

O que é o consumo líquido de caixa?

Subtraem-se as receitas operacionais mensais aos custos mensais; um resultado positivo representa consumo líquido de caixa.

Como se calcula a autonomia?

Divide-se o caixa disponível pelo consumo líquido mensal. Se o consumo for zero ou negativo, este modelo simples não indica autonomia limitada.

O resultado garante o caixa futuro?

Não. É uma estimativa simples baseada nos dados introduzidos; o fluxo de caixa real pode variar.

Limitações importantes

São aceitos apenas inteiros não negativos até 9.007.199.254.740.991. Frações e números negativos não são aceitos.

Perguntas frequentes

O que é binário?

Binário é um sistema de base 2 que usa apenas os dígitos 0 e 1.

É possível converter de binário para decimal aqui?

Não. Esta página converte apenas inteiros decimais para binário.

Zeros à esquerda são exibidos?

Não. O resultado usa a representação binária padrão mais curta.

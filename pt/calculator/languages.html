Idiomas e cobertura de páginas

O Friendly Calculator está criando uma biblioteca multilíngue de calculadoras. Escolha um idioma no cabeçalho de qualquer página. Quando ainda não houver uma versão traduzida de uma página específica, o site mantém você nessa mesma página em inglês e exibe a navegação no idioma selecionado, em vez de direcioná-lo para outra página inicial.

Importante: “Todos os idiomas” não pode significar todos os idiomas falados no mundo sem uma equipe de tradução para cada idioma. Atualmente, o site oferece as edições nos idiomas abaixo e tem uma alternativa segura na mesma página para todas as demais páginas públicas. Vamos ampliar a cobertura página por página, em vez de publicar traduções automáticas enganosas.

Como funciona a alternativa na mesma página

  1. Selecione um idioma no cabeçalho.
  2. Se a URL traduzida existir, você abrirá essa página traduzida.
  3. Se ela não existir, será aberta a página equivalente em inglês, com a navegação no idioma selecionado e um aviso claro sobre a disponibilidade.
  4. A calculadora continuará funcionando, e você poderá voltar a uma página traduzida pelo seletor de idioma a qualquer momento.

Política de tradução e correções

As páginas traduzidas devem preservar a fórmula original, as unidades, as premissas, os avisos de segurança e os links para as fontes. Uma tradução não pode alterar uma conclusão financeira, tributária, de saúde ou jurídica. Se encontrar um erro de tradução ou a ausência de uma página de grande relevância, envie a URL pela página de contato. Consulte a política editorial e a metodologia de cálculo.

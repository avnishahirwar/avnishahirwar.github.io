Friendly Calculator Embed Network

Ermöglichen Sie Lesern Berechnungen, ohne Ihren Artikel verlassen zu müssen. Das Widget wird auf Friendly Calculator ausgeführt, sodass Ihre Website keine Besuchereingaben aus dem iframe erhält. Die Quellenangabe unter dem Widget führt Leser zur passenden Rechnerseite.

  1. Öffnen Sie den kostenlosen Einbettungs-Builder.
  2. Wählen Sie einen Rechner aus und kopieren Sie den responsiven iframe-Code.
  3. Fügen Sie ihn in das HTML Ihrer Website oder einen benutzerdefinierten HTML-Block ein.
  4. Lassen Sie die Quellenangabe und den Link zur entsprechenden Rechnerseite unverändert.

FAQ zum Embed Network

Wer kann die kostenlosen Widgets nutzen?

Blogs, Schulen, Hochschulen, Bildungsportale, Publisher, Community-Websites und Unternehmen können den öffentlichen iframe-Builder für einen echten Nutzen für Leser oder Lernende verwenden, sofern sie die Regeln zur Quellenangabe und zur zulässigen Nutzung einhalten.

Erhält Friendly Calculator Besuchereingaben?

Der Browser-Rechner führt seine Berechnung auf der Friendly-Calculator-Seite innerhalb des iframe aus. Die Host-Website erhält diese Eingaben nicht über die Einbettung. Weitere Informationen zu Analysen, Hosting und API finden Sie in der Datenschutzerklärung.

Kann ich das Branding von Friendly Calculator entfernen?

Nein. Beim kostenlosen Netzwerk sind die sichtbare Quellenangabe „Powered by Friendly Calculator“ und ein Link zur entsprechenden Rechnerseite erforderlich. Kontaktieren Sie uns für genehmigte individuelle Lösungen oder White-Label-Angebote.

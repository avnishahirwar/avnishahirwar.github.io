Sprachen & Seitenabdeckung

Friendly Calculator baut eine mehrsprachige Rechnerbibliothek auf. Wählen Sie auf einer beliebigen Seite eine Sprache im Kopfbereich aus. Wenn eine bestimmte Seite noch nicht übersetzt wurde, bleiben Sie auf derselben Seite auf Englisch, und die Navigation wird in der ausgewählten Sprache angezeigt, anstatt Sie zu einer anderen Startseite weiterzuleiten.

Wichtig: „Alle Sprachen“ kann nicht jede weltweit gesprochene Sprache umfassen, wenn es kein Übersetzungsteam für jede Sprache gibt. Die aktuelle Website unterstützt die unten aufgeführten Sprachversionen und bietet für alle anderen öffentlichen Seiten eine sichere Ausweichlösung auf derselben Seite. Wir werden die Seitenabdeckung schrittweise erweitern, statt irreführende maschinelle Übersetzungen zu veröffentlichen.

So funktioniert die Ausweichlösung auf derselben Seite

  1. Wählen Sie im Kopfbereich eine Sprache aus.
  2. Wenn die übersetzte URL verfügbar ist, wird die übersetzte Seite geöffnet.
  3. Wenn sie nicht verfügbar ist, wird die entsprechende englische Seite mit der Navigation in der ausgewählten Sprache und einem deutlichen Hinweis zur Verfügbarkeit geöffnet.
  4. Der Rechner funktioniert weiterhin, und Sie können jederzeit über die Sprachauswahl zu einer übersetzten Seite zurückkehren.

Richtlinien für Übersetzungen und Korrekturen

Übersetzte Seiten sollten die ursprüngliche Formel, Einheiten, Annahmen, Sicherheitshinweise und Quellenlinks beibehalten. Eine Übersetzung darf keine finanziellen, steuerlichen, gesundheitlichen oder rechtlichen Schlussfolgerungen ändern. Wenn Sie eine fehlerhafte Übersetzung oder eine wichtige fehlende Seite entdecken, senden Sie bitte die URL über die Kontaktseite. Siehe auch die redaktionellen Richtlinien und die Berechnungsmethodik.

Synthetic Division Calculator

Enter polynomial coefficients in descending powers and the value c for the divisor x − c. The calculator shows the synthetic bottom row, quotient, remainder and division identity.

Formula and method

For P(x) = anxn + … + a0 and divisor x − c, set bn = an and compute bk = ak + c bk+1 for k = n − 1 down to 0. The quotient coefficients are bn, …, b1; b0 is the remainder P(c).

The calculator uses the entered values and displays the result in the browser. It does not send your calculation inputs to a server.

Worked example

For P(x) = 2x3 − 3x2 + 4x − 5 and c = 2, the bottom row is 2, 1, 6, 7. The quotient is 2x2 + x + 6 and the remainder is 7. Check: P(x) = (x − 2)(2x2 + x + 6) + 7.

Scope and limitations

The divisor is restricted to a monic linear polynomial x − c; this tool does not divide by ax + b when a ≠ 1 or by higher-degree polynomials. Enter finite real coefficients in descending-power order, using zero for missing powers. Maximum degree: 20. Decimal inputs use binary floating-point arithmetic, so tiny displayed remainders can reflect rounding rather than exact divisibility.

Frequently asked questions

What divisor does this support?

Only a monic linear divisor x − c. For x + 2, enter c = −2. A divisor such as 2x − 4 is outside the supported form.

What is the remainder?

The remainder is P(c), the value of the dividend polynomial at the entered root c.

How do I represent a missing term?

Enter its coefficient as zero. For 2x^3 + 4x − 5, enter 2, 0, 4, -5.

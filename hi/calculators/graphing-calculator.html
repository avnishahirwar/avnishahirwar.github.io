Supported functions and notation

Use x as the variable, pi for π and e for Euler's number. Supported functions include sin, cos, tan, inverse trigonometric functions, sqrt, abs, log, log10, exp, floor, ceil, round, sinh, cosh and tanh. Angles are in radians. Use explicit multiplication, such as 2*x, and parentheses to control order.

Supported operators are addition (+), subtraction (−), multiplication (*), division (/), remainder (%) and powers (^). Up to five expressions can be plotted at once.

How to use the graphing calculator

  1. Enter one or more expressions using x as the independent variable.
  2. Choose the visible x and y ranges, then select Plot graph.
  3. Compare the curves and adjust the ranges to inspect a region in more detail.
  4. Use the table of values to compare numerical outputs around a selected x value.

This tool plots 2D functions of the form y = f(x). It is not a computer algebra system and does not certify roots, derivatives, integrals or exact intersections. Curves are sampled numerically for display, so very narrow features or discontinuities may need a closer range.

Frequently asked questions

Is this graphing calculator free?

Yes. The graphing tool is free to use in your browser and does not require an account.

Can I plot more than one equation?

Yes. You can add up to five expressions and compare their curves on the same coordinate plane.

Does it support 3D graphs or implicit equations?

No. This version plots 2D explicit functions y = f(x). It does not currently plot 3D surfaces, polar curves or implicit equations.

Are trigonometric angles in degrees?

No. Trigonometric functions use radians. Convert degrees to radians before entering them.

Formula and method

For a nonzero real polynomial p(x), count adjacent sign changes in its nonzero coefficients to get V(p). The number of positive real roots, counted with multiplicity, is V(p), V(p) − 2, … down to the nonnegative value of matching parity. Apply the same rule to p(−x) for negative roots. Trailing zero coefficients give the multiplicity of x = 0.

The calculator uses the entered values and displays the result in the browser. It does not send your calculation inputs to a server.

Worked example

For p(x) = x4 − 2x2 + 1, the nonzero signs are +, −, +, so V(p) = 2. Since p(−x) = p(x), V(p(−x)) = 2. The possible positive and negative counts are each 2 or 0. In fact p(x) = (x − 1)2(x + 1)2, so this example has two roots of each sign when multiplicity is counted.

Scope and limitations

This theorem gives a finite list of possible counts, not root locations and not a guarantee that every listed count occurs. Inputs must be real finite coefficients in descending-power order, with zeros for gaps; exact zero is treated as zero, with no tolerance threshold. The zero polynomial is rejected. Maximum degree: 20. Numerical formatting does not change the sign classification of parsed coefficients.

Frequently asked questions

Does the calculator find the roots?

No. Descartes’ rule bounds and restricts possible positive/negative real-root counts. It does not locate roots; use a root solver or factorization method for that.

Why are there multiple possible counts?

The actual count differs from the sign-change count by an even nonnegative integer, so the rule lists the parity-compatible possibilities.

How should I enter missing powers?

Include a zero coefficient for each missing power, in descending order. For x^4 − 2x^2 + 1, enter 1, 0, -2, 0, 1.

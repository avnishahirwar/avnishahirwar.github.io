Matrix formulas

  • Addition and subtraction operate on corresponding elements.
  • Multiplication uses row-by-column dot products.
  • The determinant indicates whether a square matrix has an inverse.
  • The transpose exchanges rows and columns.
  • An inverse exists only when det(A) is not zero.

This tool supports square 2×2 and 3×3 matrices. It is an educational calculator, not a computer algebra system for arbitrary matrix dimensions.

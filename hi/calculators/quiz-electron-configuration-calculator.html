Quiz: Electron Configuration Calculator

Practice ground-state electron configurations for neutral atoms with atomic numbers 1–36.

Enter your values

Formula / method

Fill orbitals in increasing-energy order, respecting subshell capacities s², p⁶, d¹⁰ and f¹⁴.

How to use

Enter an atomic number from 1–36 and type the ground-state configuration, for example 1s2 2s2 2p6.

Assumptions and limitations

Uses the Aufbau filling order and does not model excited states, ions or all transition-metal exceptions. This is a practice quiz, not an authoritative spectroscopic reference.

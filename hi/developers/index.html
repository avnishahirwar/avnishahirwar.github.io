4. Compatibility and privacy

  • Use an HTML or custom-code block that allows iframe embeds.
  • Some hosted website builders restrict iframes; check your platform's embed settings.
  • Set a suitable height and test on mobile and desktop.
  • The embedded calculator is served from Friendly Calculator. Your site does not need to receive calculation inputs.

Read API documentation

Security: Never place an API key in browser JavaScript, an iframe URL, a mobile app bundle or a public repository. Keep API requests on your server and store the key in a secret environment variable. The iframe widget does not send visitor calculation inputs to your website.

Frequently asked questions

Is the calculator embed free?

The basic public iframe embed is offered without an API key or separate setup charge. Normal hosting and service availability limits still apply.

Do I need to install a plugin?

No plugin is required if your website editor supports custom HTML or iframe blocks.

Can I change the calculator's formula?

No. The embedded calculator uses the calculator and formula maintained by Friendly Calculator.

Can I remove the Friendly Calculator attribution?

Please keep the attribution intact. It identifies the provider and helps visitors find the original calculator.

Is a public API available?

Not currently advertised. Use the iframe builder until a separately documented API is released.

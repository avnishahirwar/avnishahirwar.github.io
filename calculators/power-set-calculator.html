Formula and method

For a finite set S with n distinct elements, |P(S)| = 2n. Each element is either included or excluded from a subset, giving two independent choices per element. The empty subset is included.

The calculator uses the entered values and displays the result in the browser. It does not send your calculation inputs to a server.

Worked example

For S = {a, b}, there are 22 = 4 subsets: ∅, {a}, {b}, and {a, b}. For S = ∅, P(S) = {∅}, so the power set has one member.

Scope and limitations

This is a set calculator, not a multiset calculator: leading/trailing whitespace is trimmed and exact duplicate labels are removed, while letter case remains significant. At most 10 distinct labels are accepted (1,024 subsets); each label is limited to 40 characters. All subsets are generated rather than silently truncated.

Frequently asked questions

Why is the empty set included?

Every set has an empty subset. For the empty set itself, its power set contains that one subset: P(∅) = {∅}.

Are repeated labels counted twice?

No. The calculator trims labels and removes exact duplicates. For example, “a, a” is treated as the set {a}.

Does order matter?

No. A set is unordered; the displayed order only follows the order of first entry.

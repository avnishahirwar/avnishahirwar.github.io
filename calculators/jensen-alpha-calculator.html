Jensen's Alpha Calculator

Estimate a portfolio's Jensen alpha using portfolio return, benchmark return, risk-free rate and beta.

Formula and calculation method

Jensen alpha = portfolio return − [risk-free rate + beta × (market return − risk-free rate)]. All returns must use the same period and percentage basis.

Worked example

With portfolio return 12%, risk-free rate 4%, market return 10% and beta 1.1, alpha is 1.4 percentage points.

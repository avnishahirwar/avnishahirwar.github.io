Cat Pregnancy Calculator

Estimate a cat's expected queening date from a recorded mating date using a typical gestation duration and reference range.

Enter your values

Formula

Estimated due date = mating date + 65 days. A reference range of 58–72 days from breeding is shown because timing varies.

How to use this calculator

  1. Enter each value in the unit shown.
  2. Check that the date or genotype matches the recorded information.
  3. Select Calculate to view the estimate and reference range.

Worked example

Enter your own values to see how the calculation changes. No example date is pre-filled, so the result uses the date you choose.

Assumptions and limitations

This is a calendar estimate, not confirmation of pregnancy or a veterinary assessment. Contact a veterinarian for pregnancy confirmation, health concerns or unexpected timing. This tool provides an educational estimate only. Review the reference sources where applicable.

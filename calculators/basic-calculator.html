Basic Calculator

Perform everyday arithmetic with a simple on-screen calculator. Add, subtract, multiply, divide, work with decimals and calculate percentages.

Open the basic calculator

What can this calculator do?

  • Addition (+) and subtraction (−)
  • Multiplication (×) and division (÷)
  • Decimal calculations
  • Percentage conversion
  • Change a number between positive and negative
  • Clear the display and correct the current entry

How to use the calculator

  1. Open the basic calculator.
  2. Enter a number using the keypad.
  3. Select an arithmetic operator.
  4. Enter the next number and press equals.
  5. Use AC to reset the calculator for a new calculation.

Basic arithmetic formulas

Addition: a + b
Subtraction: a − b
Multiplication: a × b
Division: a ÷ b (b must not be zero)

Percentage button

The percentage key converts the displayed value to its decimal equivalent. For example, 25% becomes 0.25. To find 25% of 200, enter 200 × 25% and then equals.

Accuracy and limitations

This is a standard arithmetic calculator for everyday calculations. Results are calculated using JavaScript number arithmetic and displayed with practical precision. For tax, lending, investment, accounting or other regulated decisions, verify figures with the relevant official source or a qualified professional.

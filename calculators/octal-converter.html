Octal Converter

Convert a non-negative whole number from decimal notation into octal (base 8).

How to use this calculator

Enter a decimal whole number from 0 through 9,007,199,254,740,991. The calculator converts that integer into base 8. It does not parse octal text into decimal.

Formula and method

Repeatedly divide the input by 8. Each remainder is one octal digit (0–7). Read the remainders from last to first. The place values are powers of eight: 8⁰, 8¹, 8² and so on.

Worked example

For decimal 83: 83 ÷ 8 = 10 remainder 3; 10 ÷ 8 = 1 remainder 2; 1 ÷ 8 = 0 remainder 1. Reverse the remainders to get 123. Check: 1 × 64 + 2 × 8 + 3 = 83.

Understanding the result

Octal is a positional number system with eight symbols, 0 through 7. Each octal digit represents three binary bits, which is why it appears in some computing and Unix permission notation.

Important limitations

  • Only non-negative safe integers are supported; fractions, negative values and larger integers are not accepted.
  • This tool converts decimal to octal only; it does not validate or decode arbitrary octal strings.
  • Leading zeroes are not added to the output.

Frequently asked questions

Why does octal use only digits 0 through 7?

Base 8 has eight digit symbols, starting at zero, so the largest single digit is 7. A value of eight is written as 10 in octal.

How can I check an octal result?

Multiply each digit by its place value (a power of 8) and add the results. For 123₈, that is 1 × 64 + 2 × 8 + 3 = 83₁₀.

Is octal related to binary?

Yes. Every octal digit maps to a three-bit binary group, making octal a compact way to express binary data.

What digits are used in octal? Only 0, 1, 2, 3, 4, 5, 6 and 7.

Formulas used by this calculator

The Trapezoid Perimeter Calculator works with 14 quantities and 35 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Angle Alpha (angleAlpha) = asin(h/c)
  • Angle Delta (angleDelta) = asin(h/d)
  • b (b) = P - a - c - d
  • a (a) = P - b - c - d
  • c (c) = P - a - b - d
  • d (d) = P - a - b - c
  • P (P) = a + b + c + d
  • Angle Beta (angleBeta) = PI - angleAlpha

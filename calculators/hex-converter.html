Hex Converter

Convert a non-negative whole number from decimal notation into hexadecimal (base 16).

How to use this calculator

Enter a decimal whole number from 0 through 9,007,199,254,740,991. The calculator converts that exact integer to base 16; it does not convert hexadecimal text back to decimal.

Formula and method

Repeatedly divide the decimal integer by 16. Record each remainder (0–9, then A–F for 10–15), and read the remainders in reverse order. Equivalently, each hexadecimal digit is a coefficient of a power of 16.

Worked example

For decimal 255: 255 ÷ 16 = 15 remainder 15 (F); 15 ÷ 16 = 0 remainder 15 (F). Reading remainders backwards gives FF. Check: 15 × 16 + 15 = 255.

Understanding the result

Hexadecimal is a positional base-16 notation commonly used for colour codes, memory addresses and compact representation of binary data. The converted value is numerically identical to the input.

Important limitations

  • Accepts non-negative safe integers only; fractions, negative values and values above 9,007,199,254,740,991 are outside the supported range.
  • This page converts decimal to hexadecimal only; it does not parse prefixed strings such as 0xFF.
  • Letter case is a display convention; this tool displays A–F in uppercase.

Frequently asked questions

What does A mean in hexadecimal?

A represents decimal 10. The remaining letters continue B = 11, C = 12, D = 13, E = 14 and F = 15.

Why is hexadecimal useful in computing?

One hexadecimal digit corresponds exactly to four binary bits, so long binary values can be written more compactly.

Is FF the same value as decimal 255?

Yes. FF means 15 × 16 + 15, which equals 255 in decimal notation.

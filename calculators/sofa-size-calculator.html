How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Sofa Size Calculator works with 18 quantities and 9 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Sofa Frame Height2 (sofaFrameHeight2) = (liftWidth - 2)
  • Sofa Total Depth (sofaTotalDepth) = (liftDepth - 2)
  • Sofa Total Width (sofaTotalWidth) = (liftHeight - 2)
  • Width (width) = (wallLength - 36)
  • Width2 (width2) = (liftHeight - 14)
  • Width1 (width1) = (wallLength - 24)
  • Sofa Frame Height3 (sofaFrameHeight3) = (widthOfDoor - 2)
  • Sofa Frame Height4 (sofaFrameHeight4) = (hallwayWidth - 2)

What the sigmoid function calculates

The logistic sigmoid maps any real input to a value strictly between 0 and 1. It is used in statistics and machine learning to transform a score into a bounded output.

Formula

σ(x) = 1 ÷ (1 + e−x)

Worked examples

  • When x = 0, σ(x) = 0.5.
  • When x = 2, σ(x) is approximately 0.8808.
  • When x = −2, σ(x) is approximately 0.1192.

Interpretation

A sigmoid output is not automatically a calibrated probability. Its meaning depends on the model, data and decision threshold where it is used.

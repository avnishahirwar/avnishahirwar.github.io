RAID Calculator

This RAID calculator will help you decide which disk configuration (RAID level) is right for you, based on usable capacity, fault tolerance, performance, and cost.

Enter values

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The RAID Calculator works with 88 quantities and 135 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Capacity raid1 (capacity_raid1) = disk_size
  • Unavailable capacity raid5 (unavailable_capacity_raid5) = disk_size
  • Unavailable capacity raid5e (unavailable_capacity_raid5e) = 2 × disk_size
  • Unavailable capacity raid6 (unavailable_capacity_raid6) = 2 × disk_size
  • Disk size (disk_size) = capacity_raid1
  • Read speed gain raid0 (read_speed_gain_raid0) = num_disks_raid0
  • Write speed gain raid0 (write_speed_gain_raid0) = num_disks_raid0
  • Read speed gain raid1 (read_speed_gain_raid1) = num_disks_raid1

127 further rearrangements of the same relations let you solve for other quantities.

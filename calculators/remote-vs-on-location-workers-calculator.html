How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Remote vs. On-Location Workers Calculator works with 46 quantities and 34 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Total Cost 2 (TotalCost_2) = OneTime_2 + RecCost_2 × periods
  • One Time 2 (OneTime_2) = furniture + hardware + software
  • Furniture (furniture) = OneTime_2 - hardware - software
  • Hardware (hardware) = OneTime_2 - furniture - software
  • Software (software) = OneTime_2 - furniture - hardware
  • Rec Cost 2 (RecCost_2) = (-OneTime_2 + TotalCost_2)/periods
  • Periods (periods) = (-OneTime_2 + TotalCost_2)/RecCost_2
  • Number Of Employees (numberOfEmployees) = TotalCost/(OneTime + RecCost × periods)

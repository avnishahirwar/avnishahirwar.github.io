Absolute Value Inequality Calculator

Enter a, b and a positive bound to calculate the solution intervals for |a × x + b| less than or greater than the bound.

Use the calculator

How to use this calculator

Enter a non-zero coefficient a, offset b and positive bound c. The calculator reports both strict inequality forms and sorts interval endpoints even when a is negative.

Formula and methodology

For c > 0 and a ≠ 0, |a x + b| < c gives the interval between (−c − b)/a and (c − b)/a. |a x + b| > c gives the two outside intervals. Strict inequality endpoints are excluded.

Worked example

For |2x + 1| < 5, the solution is −3 < x < 2. For |2x + 1| > 5, x < −3 or x > 2.

Important limitations

Results follow the mathematical definitions and assumptions stated on this page. Check the displayed inputs and rounding before using results in coursework or technical work.

Frequently asked questions

Are endpoints included?

No. This tool solves strict less-than and greater-than inequalities, so boundary points are excluded.

What happens if the bound is zero?

This calculator requires a positive bound to show the two strict-inequality interval forms.

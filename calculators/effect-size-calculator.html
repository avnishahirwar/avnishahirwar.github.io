How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Effect Size Calculator works with 8 quantities and 10 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Variance (variance) = abs(pow(correlation, 2))
  • Control sample (control_sample) = effect_size × sd_pooled + exp_sample
  • Exp sample (exp_sample) = control_sample - effect_size × sd_pooled
  • Effect size (effect_size) = (control_sample - exp_sample)/sd_pooled
  • Sd pooled (sd_pooled) = (control_sample - exp_sample)/effect_size
  • Correlation (correlation) = effect_size/sqrt(pow(effect_size, 2) + 4)
  • Sd control (sd_control) = sqrt(-pow(sd_exp, 2) + 2 × pow(sd_pooled, 2))
  • Sd exp (sd_exp) = sqrt(-pow(sd_control, 2) + 2 × pow(sd_pooled, 2))

2 further rearrangements of the same relations let you solve for other quantities.

Trihybrid Cross Calculator - Punnett Square

Estimate offspring phenotype probabilities for three independently assorting Mendelian traits from two parental genotypes.

Enter your values

Formula

Enumerate each parent's eight possible gametes, combine all 64 equally likely pairings, and group offspring by dominant/recessive phenotype at each locus.

How to use this calculator

  1. Enter each value in the unit shown.
  2. Check that the date or genotype matches the recorded information.
  3. Select Calculate to view the estimate and reference range.

Worked example

Enter your own values to see how the calculation changes. No example date is pre-filled, so the result uses the date you choose.

Assumptions and limitations

Assumes three autosomal loci with complete dominance and independent assortment. Linkage, epistasis, incomplete dominance and unequal viability are not modelled. This tool provides an educational estimate only. Review the reference sources where applicable.

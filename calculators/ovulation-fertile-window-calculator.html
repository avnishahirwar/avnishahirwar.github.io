Ovulation & Fertile Window Calculator

Estimate a possible ovulation date and calendar fertile window using an average cycle length.

Enter a date and cycle length.
Important: This calendar method cannot confirm ovulation, fertility or pregnancy. Do not use it as the only method of contraception or for urgent medical decisions.

How the estimate works

The tool estimates the next period by adding the average cycle length to the first day of the last period. It then estimates ovulation about 14 days before that next period and displays a broad calendar window from five days before the estimate through one day after it. This is a simplified planning model. Actual ovulation timing can vary, especially with irregular cycles, illness, stress, travel, medicines, breastfeeding or hormonal changes.

Use the result responsibly

Use the output as a prompt to learn more, not as proof of a biological event. If you are trying to conceive, a clinician can explain appropriate options. If you are avoiding pregnancy, ask a qualified healthcare professional about reliable contraception. A pregnancy test and professional advice are more appropriate than relying on a calendar estimate when a period is late or pregnancy is possible.

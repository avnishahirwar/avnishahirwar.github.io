Power Function Calculator

The power function calculator helps you find the result of any number to the power of any other, which could be a positive, negative, or even decimal exponent.

Enter values

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Power Function Calculator works with 12 quantities and 8 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Exponent Checker (exponentChecker) = mod(1/exponent, 2)
  • Power (power) = pow(base, exponent)
  • Exponent (exponent) = log(power)/log(base)
  • Base (base) = pow(power, 1/exponent)
  • Power Checker (powerChecker) = pow(ceil(base), exponent)
  • Base New (baseNew) = -pow(abs(power), 1/exponent)

2 further rearrangements of the same relations let you solve for other quantities.

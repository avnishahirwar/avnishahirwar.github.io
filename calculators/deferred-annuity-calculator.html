How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Deferred Annuity Calculator works with 32 quantities and 8 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • g (g) = pow(g_p + 1, q) - 1
  • G p (g_p) = pow(g + 1, 1/q) - 1
  • Start Date (StartDate) = first_day + 438291/80
  • First day (first_day) = StartDate - 438291/80
  • q (q) = log(g + 1)/log(g_p + 1)
  • G p Def (g_pDef) = pow(gDef + 1, 1/qDef) - 1
  • G Def (gDef) = pow(g_pDef + 1, qDef) - 1
  • Q Def (qDef) = log(gDef + 1)/log(g_pDef + 1)

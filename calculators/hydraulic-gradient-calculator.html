Formulas used by this calculator

The Hydraulic Gradient Calculator works with 5 quantities and 6 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Hydraulic Gradient (hydraulicGradient) = headChange/distance
  • Head Point1 (headPoint1) = headChange + headPoint2
  • Head Change (headChange) = headPoint1 - headPoint2
  • Head Point2 (headPoint2) = -headChange + headPoint1
  • Distance (distance) = headChange/hydraulicGradient

What is a mutual fund return calculator?

A mutual fund return calculator helps an investor review how an investment has changed in value over a chosen period. This version is a return-review tool: enter the amount originally invested, the current value shown by your fund platform or statement, and the time you held the investment. It calculates the rupee gain or loss, the absolute percentage return and the compound annual growth rate (CAGR).

Mutual funds pool money from investors and invest it according to a scheme's stated objective. The value of a mutual fund investment can rise or fall with the market and the assets held by the scheme. The calculator does not decide whether a fund is suitable, and a past return is not a promise of a future result.

Formula and worked example

Gain or loss = Current value − Amount invested.

Absolute return (%) = (Gain or loss ÷ Amount invested) × 100.

CAGR (%) = [(Current value ÷ Amount invested)1 ÷ years − 1] × 100, when the holding period and values allow an annualised calculation.

Example: suppose an investor put ₹50,000 into a mutual fund and the value shown today is ₹62,000 after 3 years. The gain is ₹12,000. The absolute return is ₹12,000 ÷ ₹50,000 × 100 = 24%. CAGR is approximately 7.43% per year. Absolute return describes the total change over the full period; CAGR expresses a smoothed annual rate for comparison. Neither figure explains the path the investment took between the start and end dates.

This simple method assumes one initial investment and one ending value. It does not calculate XIRR for multiple purchases, SIP instalments, withdrawals or cash flows.

Tips for interpreting mutual fund returns

Use the same valuation date and currency for the invested and current values. Check whether the statement includes all units, switches, redemptions and distributions relevant to the investment. If you have made several investments on different dates, use a cash-flow method such as XIRR rather than treating all contributions as one lump sum. Review fund costs, taxes, exit loads, risk level and the scheme's official documents separately.

Do not choose a fund only because its recent return is high. Compare performance with an appropriate benchmark and category over more than one period, while considering volatility, investment objective, costs and your own circumstances. A bank deposit and a market-linked mutual fund have different risk, liquidity and return characteristics; the figures are not directly interchangeable.

Frequently asked questions

Is the return guaranteed?

No. The calculator only compares values you enter. Mutual fund values are market-linked and can go down as well as up.

What is the difference between absolute return and CAGR?

Absolute return is the total percentage change over the entire period. CAGR expresses the start-to-end change as a smoothed annual rate.

Can I use this for a monthly SIP?

Not accurately when there are multiple instalments on different dates. Use an XIRR-based calculator for SIP cash flows; this page assumes one initial investment.

Does the result include tax, expense ratio or exit load?

No. Enter values that reflect the basis you want to compare, and check taxes, scheme expenses and exit loads separately using current official information.

Does Friendly Calculator fetch live mutual fund NAV data?

No. The calculator uses only the invested amount, current value and holding period that you enter.

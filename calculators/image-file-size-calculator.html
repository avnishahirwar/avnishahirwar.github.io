Image File Size Calculator

Enter image dimensions, bits per channel, colour channels and an assumed compression ratio to estimate file size.

Use the calculator

How to use this calculator

Use pixel dimensions and the image's actual bit depth and channel count. The compression ratio is an estimate, not a prediction of a particular encoder.

Formula and methodology

Uncompressed bytes = width × height × bits per channel × channels ÷ 8. Estimated compressed bytes = uncompressed bytes ÷ compression ratio.

Worked example

A 4000 × 3000 image with 8 bits per channel and 3 channels contains 36,000,000 uncompressed bytes before file-format overhead.

Important limitations

Results are estimates based on the inputs and assumptions shown. Display specifications, file formats, frame-rate conventions and lens characteristics can vary; confirm the actual device or production settings before relying on the result.

Frequently asked questions

Does this include metadata?

No. Headers, metadata, thumbnails, colour profiles and file-format overhead are not included.

Will a JPEG always have the same compression ratio?

No. File size depends on image content, quality settings, chroma subsampling and encoder implementation.

How it works

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Annualized Rate of Return Calculator works with 3 quantities and 3 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Annualized rate of return (annualized_rate_of_return) = pow(period_rate + 1, period) - 1
  • Period rate (period_rate) = pow(annualized_rate_of_return + 1, 1/period) - 1
  • Period (period) = log(annualized_rate_of_return + 1)/log(period_rate + 1)

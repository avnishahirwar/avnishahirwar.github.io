How it works

Formulas used by this calculator

The Trig Function Calculator works with 15 quantities and 17 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Sin print (sin_print) = sin(angle)
  • Cos print (cos_print) = cos(angle)
  • Tan print (tan_print) = tan(angle)
  • Cot print (cot_print) = cot(angle)
  • Angle degrees print (angle_degrees_print) = 180 × angle/PI
  • Angle (angle) = asin(sin_print)
  • Base angle (base_angle) = mod(angle_degrees_print, 360)
  • Tan check first (tan_check_first) = (1/90) × abs(angle_degrees_print)

9 further rearrangements of the same relations let you solve for other quantities.

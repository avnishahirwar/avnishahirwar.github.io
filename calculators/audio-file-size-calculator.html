How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Audio File Size Calculator works with 6 quantities and 7 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Audio File Size (audioFileSize) = bitRate × duration
  • Duration (duration) = audioFileSize/bitRate
  • Bit Rate (bitRate) = audioFileSize/duration
  • Sample Rate (sampleRate) = bitRate/(bitdepth × channels)
  • Channels (channels) = bitRate/(bitdepth × sampleRate)
  • Bitdepth (bitdepth) = bitRate/(channels × sampleRate)

1 further rearrangement of the same relations let you solve for other quantities.

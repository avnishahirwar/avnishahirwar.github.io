Gear Ratio and Output Speed Calculator

Find the gear ratio, output speed and ideal torque multiplier of a simple two-gear drive.

Enter your values

Formula and methodology

Gear ratio = driven teeth ÷ driver teeth. Output speed = input speed ÷ ratio. Ideal output torque = input torque × ratio (ignoring losses).

Worked example

With Teeth on driver gear 20, Teeth on driven gear 60, Input speed 1,500, the calculator gives: Gear ratio = 3; Output speed (rpm) = 500; Ideal torque multiplier = 3.

How to read the result

A ratio above 1 reduces speed and increases torque. Real gear sets lose some power to friction, so measured torque is slightly lower.

Frequently asked questions

Does the direction reverse?

Yes, meshing external gears turn in opposite directions. An idler gear restores direction without changing the ratio.

How do I handle several gear stages?

Multiply the ratios of each stage together.

Assumptions and limitations

This tool uses idealised textbook formulas for learning and quick estimates. Real systems include friction, losses, tolerances and measurement error. Do not use it as the only basis for safety-critical or regulated engineering design.

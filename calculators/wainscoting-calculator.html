Wainscoting Calculator

This wainscoting calculator will help you calculate the measurements and dimensions concerning your DIY wainscoting or board and batten project. We also explain the basics of wainscoting installation and some other information you might find useful.

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Wainscoting Calculator works with 14 quantities and 20 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Frame Height recessed Panel (frameHeight_recessedPanel) = -baseDepth - capDepth + chairRailHeight - topMargin
  • Chair Rail Height (chairRailHeight) = baseDepth + capDepth + frameHeight_recessedPanel + topMargin
  • Number Of Panels (numberOfPanels) = (-stileWidth + wallLength)/(panelWidth_shadowBox + stileWidth)
  • Frame Height shadow Box (frameHeight_shadowBox) = -baseDepth - bottomMargin - capDepth + chairRailHeight - topMargin
  • Top Margin (topMargin) = -baseDepth - capDepth + chairRailHeight - frameHeight_recessedPanel
  • Base Depth (baseDepth) = -capDepth + chairRailHeight - frameHeight_recessedPanel - topMargin
  • Cap Depth (capDepth) = -baseDepth + chairRailHeight - frameHeight_recessedPanel - topMargin
  • Panel Width shadow Box (panelWidth_shadowBox) = (-numberOfPanels × stileWidth - stileWidth + wallLength)/numberOfPanels

12 further rearrangements of the same relations let you solve for other quantities.

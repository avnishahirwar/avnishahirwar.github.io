How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Pleated Skirt Calculator works with 13 quantities and 21 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Pleat width box (pleat_width_box) = 3 × waist/n_of_pleats
  • Pleat width knife (pleat_width_knife) = 2 × waist/n_of_pleats
  • N of pleats (n_of_pleats) = 3 × waist/pleat_width_box
  • Skirt band width (skirt_band_width) = 3 × seam_allowance + waist
  • Skirt fabric width box (skirt_fabric_width_box) = seam_allowance + 3 × waist
  • Skirt fabric width knife (skirt_fabric_width_knife) = seam_allowance + 2 × waist
  • Skirt fabric length (skirt_fabric_length) = 2 × seam_allowance + skirt_length
  • Seam allowance (seam_allowance) = skirt_fabric_width_box - 3 × waist

13 further rearrangements of the same relations let you solve for other quantities.

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Back to School Calculator works with 40 quantities and 11 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Category E (categoryE) = (itemE1)
  • Category A (categoryA) = (itemA1 + itemA2 + itemA3 + itemA4)
  • Category C (categoryC) = (itemC1 + itemC2 + itemC3 + itemC4)
  • Category B (categoryB) = (itemB1 + itemB2 + itemB3 + itemB4 + itemB5)
  • Category D (categoryD) = (itemD1 + itemD2 + itemD3 + itemD4 + itemD5)
  • Budget manually school (budget_manually_school) = budgetA_school + budgetB_school + budgetC_school + budgetD_school + budgetE_school
  • Budget C school (budgetC_school) = -budgetA_school - budgetB_school - budgetD_school - budgetE_school + budget_manually_school
  • Budget A school (budgetA_school) = -budgetB_school - budgetC_school - budgetD_school - budgetE_school + budget_manually_school

3 further rearrangements of the same relations let you solve for other quantities.

Percent Solution Calculator

Calculate mass/volume percentage concentration from solute mass and final solution volume.

Enter your values

Formula

% w/v = solute mass (g) ÷ final solution volume (mL) × 100.

How to use this calculator

  1. Enter each value in the unit shown beside its field.
  2. Select Calculate to view the result and intermediate values.
  3. Change the inputs to compare scenarios.

Worked example

The pre-filled values provide a sample calculation. Adjust one input at a time to understand how the result changes.

Assumptions and limitations

This page calculates only mass/volume percentage (% w/v), meaning grams of solute per 100 mL of final solution. It does not calculate % w/w or % v/v.

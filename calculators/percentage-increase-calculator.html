Percentage Increase Calculator

Enter the starting value and the increase rate to calculate how much the value rises and the resulting total.

Use the Percentage Increase Calculator

How to use this calculator

Enter the original value and the percentage increase. Use a rate of zero for no change.

Formula

Increase = Original value × Increase rate ÷ 100. New value = Original value + Increase.

Example and interpretation

A 15% increase on 100 adds 15, producing a new value of 115.

Important limitations

This tool performs the mathematical operation described above using only the values entered. Check units, data quality and the selected interpretation before relying on a result.

Frequently asked questions

How do I add a percentage to a value?

Multiply the original value by the percentage divided by 100, then add that increase to the original value.

Can I use decimal percentages?

Yes. Decimal percentage rates are supported.

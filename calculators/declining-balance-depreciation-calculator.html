Declining Balance Depreciation Calculator

Calculate depreciation and book value for a chosen year using the double-declining balance method.

Enter your values

Formula and methodology

Double-declining rate = 2 ÷ useful life. Depreciation in a year = opening book value × rate, never taking book value below salvage value.

Worked example

With Asset cost 10,00,000, Salvage value 1,00,000, Useful life 8, Year to calculate 3, the calculator gives: Depreciation rate (%) = 25; Opening book value = 5,62,500; Depreciation for the year = 1,40,625; Closing book value = 4,21,875.

How to read the result

This method charges more depreciation in early years. Tax rules in many countries prescribe their own methods and rates, so use this for accounting estimates only.

Frequently asked questions

Why does depreciation stop at salvage value?

An asset is not depreciated below its estimated salvage value, so the charge is capped.

How is this different from straight-line?

Straight-line charges the same amount each year, while declining balance front-loads the charge.

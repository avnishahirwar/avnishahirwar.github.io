How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Conversion Calculator works with 37 quantities and 64 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • F (F) = C
  • C (C) = F
  • K (K) = C
  • Other temp units 0 (other_temp_units_0) = C
  • Other temp units 1 (other_temp_units_1) = C
  • l1 (l1) = l2
  • l2 (l2) = l1
  • a2 (a2) = a1

56 further rearrangements of the same relations let you solve for other quantities.

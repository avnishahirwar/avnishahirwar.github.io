Gordon Growth Model Calculator

Estimate the intrinsic value of a dividend-paying share from next year’s dividend, required return and growth rate.

Enter your values

Formula and methodology

Value per share = D1 ÷ (r − g), where D1 is next year’s dividend, r is the required return and g is the constant growth rate (both as decimals).

Worked example

With Expected dividend next year per share 12, Required return 11, Long-term dividend growth 6, the calculator gives: Estimated value per share = 240; Implied dividend yield (%) = 5.

How to read the result

The result is very sensitive to the gap between required return and growth. A small change in either input moves the value a lot, so test a range before relying on one number.

Frequently asked questions

When does this model work poorly?

For companies that pay no dividends, have unstable payouts or grow faster than the economy indefinitely.

What happens as growth approaches the required return?

The value rises sharply and eventually becomes meaningless, which is why the model requires the required return to exceed growth.

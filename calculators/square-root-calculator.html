Square Root Calculator

Calculate the principal square root of a non-negative number. The result is the non-negative value that, when multiplied by itself, gives the input.

Use the Square Root Calculator

How to use this calculator

Enter a number greater than or equal to zero and select Calculate. The tool displays the square root and a check using the squared result.

Formula

If y = √x, then y × y = x, where x ≥ 0 and y ≥ 0.

Frequently asked questions

What is a square root?

A square root of a number is a value that multiplied by itself gives the original number.

Can I calculate a negative number?

This real-number calculator accepts non-negative inputs only.

What is the principal square root?

It is the non-negative square root, such as √25 = 5.

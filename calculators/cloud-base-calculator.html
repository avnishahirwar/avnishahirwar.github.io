Formulas used by this calculator

The Cloud Base Calculator works with 5 quantities and 8 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Cloud base altitude (cloud_base_altitude) = -2500/11 × dew_point + elevation + (2500/11) × temperature
  • Temperature (temperature) = (11/2500) × cloud_base_altitude + dew_point - 11/2500 × elevation
  • Elevation (elevation) = cloud_base_altitude + (2500/11) × dew_point - 2500/11 × temperature
  • Dew point (dew_point) = -11/2500 × cloud_base_altitude + (11/2500) × elevation + temperature
  • Cloud temperature (cloud_temperature) = -27/5000 × cloud_base_altitude + (27/5000) × elevation + temperature

3 further rearrangements of the same relations let you solve for other quantities.

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Matrix Trace Calculator works with 33 quantities and 12 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Trace 22 (trace_22) = a12 + b22
  • A12 (a12) = -b22 + trace_22
  • B22 (b22) = -a12 + trace_22
  • Trace 33 (trace_33) = a13 + b23 + c33
  • B23 (b23) = -a13 - c33 + trace_33
  • C33 (c33) = -a13 - b23 + trace_33
  • A13 (a13) = -b23 - c33 + trace_33
  • Trace 44 (trace_44) = a14 + b24 + c34 + d44

4 further rearrangements of the same relations let you solve for other quantities.

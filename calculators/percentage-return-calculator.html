How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Percentage Return Calculator works with 27 quantities and 18 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Start date (start_date) = end_date - time_diff
  • Time diff (time_diff) = end_date - start_date
  • Returned amount (returned_amount) = gain + invested_amount
  • End date (end_date) = start_date + time_diff
  • Invested amount (invested_amount) = -gain + returned_amount
  • Start date NEW (start_date_NEW) = end_date_NEW - time_diff_NEW
  • Time diff NEW (time_diff_NEW) = end_date_NEW - start_date_NEW
  • Returned amount NEW (returned_amount_NEW) = gain_NEW + invested_amount_NEW

10 further rearrangements of the same relations let you solve for other quantities.

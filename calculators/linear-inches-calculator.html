How it works

Formulas used by this calculator

The Linear Inches Calculator works with 4 quantities and 4 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Linear Inches (Linear_Inches) = Height + Length + Width
  • Length (Length) = -Height + Linear_Inches - Width
  • Height (Height) = -Length + Linear_Inches - Width
  • Width (Width) = -Height - Length + Linear_Inches

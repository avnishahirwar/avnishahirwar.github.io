Percentage Error Calculator

Compare a measured value with the true value to find absolute error and percentage error.

Enter your values

Formula and methodology

Absolute error = |measured − true|. Percentage error = |measured − true| ÷ true × 100.

Worked example

With Measured value 9.6, True or accepted value 9.81, the calculator gives: Absolute error = 0.21; Percentage error (%) = 2.14; Measured as a share of true value (%) = 97.86.

How to read the result

Percentage error shows how large a mistake is relative to the size of the thing measured, which makes errors from different experiments comparable.

Frequently asked questions

Is percentage error the same as percentage difference?

No. Percentage error compares against a known true value, while percentage difference compares two values with no reference.

Can percentage error be negative?

This version reports the absolute value. Some courses keep the sign to show over- or under-estimation.

Assumptions and limitations

This tool applies standard textbook formulas to the values you enter. Check units and rounding, and confirm important results with a second method.

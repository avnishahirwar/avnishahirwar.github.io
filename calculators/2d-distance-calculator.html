How the 2D distance calculator works

Enter the x and y coordinates for two points. The calculator finds the horizontal and vertical differences, squares both, adds them and takes the square root to return the straight-line distance.

Formulas used by this calculator

The 2D Distance Calculator works with 5 quantities and 5 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Distance (distance) = sqrt(pow(x1 - x2, 2) + pow(y1 - y2, 2))
  • x2 (x2) = x1 + sqrt((distance - y1 + y2) × (distance + y1 - y2))
  • x1 (x1) = x2 + sqrt((distance - y1 + y2) × (distance + y1 - y2))
  • y2 (y2) = y1 + sqrt((distance - x1 + x2) × (distance + x1 - x2))
  • y1 (y1) = y2 + sqrt((distance - x1 + x2) × (distance + x1 - x2))

How 2D distance is calculated

The calculator measures the straight-line distance between two points on a flat coordinate plane. It uses the horizontal and vertical differences between the coordinates.

Formula

Distance = √((x₂ − x₁)² + (y₂ − y₁)²). The formula is the Pythagorean theorem applied to the right triangle formed by the two points.

Worked example

For point A (1, 2) and point B (4, 6), the horizontal difference is 3 and the vertical difference is 4. Distance = √(3² + 4²) = √25 = 5 units.

Assumptions and limitations

  • Both points must use the same coordinate system and units.
  • The result is a straight-line distance, not a road, walking or travel distance.
  • Coordinates may be positive, negative or decimal values.
  • When solving backward for a missing coordinate from a distance, more than one reflected point can be valid; the displayed inverse equations return the positive-root branch.

Interesting fact

The Pythagorean theorem is also the basis of the Euclidean distance formula used in two-dimensional geometry, mapping and many computer-graphics calculations.

Frequently asked questions

Can coordinates be negative?

Yes. The formula uses coordinate differences, so negative and decimal coordinates are valid.

Does the answer include a unit?

The calculator returns a numeric distance. The unit is inherited from your coordinate values, so use the same unit for both axes.

Is this the same as distance travelled?

No. It gives the shortest straight-line separation between the two points, not the length of a route or path.

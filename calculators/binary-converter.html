How to use this calculator

Formula and method

Binary notation represents an integer using powers of two.

Understanding the result

Binary notation represents an integer using powers of two.

Important limitations

Only non-negative whole numbers up to 9,007,199,254,740,991 are supported. Fractions and negative numbers are not accepted.

Worked example

For decimal 10, divide by 2 to get remainders 0, 1, 0, 1. Read them from last to first: 1010₂. Check: 8 + 2 = 10.

How to verify the result

Multiply each binary digit by its corresponding power of two and add the values. The result should equal the original decimal integer.

Frequently asked questions

What is binary?

Binary is a base-2 number system that uses only the digits 0 and 1.

Does this convert binary back to decimal?

No. This page converts decimal whole numbers to binary only.

Are leading zeroes shown?

No. The result uses the shortest standard binary representation.

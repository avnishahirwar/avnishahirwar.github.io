AFR Calculator (Air-Fuel Ratio)

Calculate an air-to-fuel mass ratio and compare it with a user-supplied reference stoichiometric ratio.

Enter your values

Formula

Air-fuel ratio (AFR) = air mass ÷ fuel mass; lambda = actual AFR ÷ reference stoichiometric AFR.

How to use this calculator

  1. Enter each value in the unit shown beside its field.
  2. Select Calculate to view the result and intermediate values.
  3. Change the inputs to compare scenarios.

Worked example

The pre-filled values provide a sample calculation. Adjust one input at a time to understand how the result changes.

Assumptions and limitations

This is a mass-ratio calculation only. The reference ratio depends on fuel composition and conditions; the calculator does not assess engine safety, emissions or tuning.

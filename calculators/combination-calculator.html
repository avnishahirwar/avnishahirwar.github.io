How to use the combination calculator

Enter the total number of distinct items (n) and the number you want to select (r). The calculator returns the number of unique groups when order does not matter.

Use whole numbers only. The selected count cannot be greater than the total count. The empty selection is valid and has exactly one combination.

Combination formula

nCr = n! / (r! × (n − r)!)

The formula is nCr = n! / (r! × (n − r)!). It counts selections without treating different arrangements of the same items as separate outcomes.

Example

10C3 = 10! / (3! × 7!) = 120.

Frequently asked questions

What is a combination?

A combination is a selection where the order of the chosen items does not matter.

How is a combination different from a permutation?

A permutation counts different orders separately. A combination treats the same selected items as one group, regardless of order.

Can I select zero items?

Yes. There is exactly one way to select an empty group, so nC0 equals 1.

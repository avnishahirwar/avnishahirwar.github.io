Scientific calculator functions

This tool supports addition, subtraction, multiplication, division, parentheses, powers, square roots, absolute values, exponential functions, common logarithms, natural logarithms and trigonometry. In degree mode, sin(30) evaluates the sine of 30 degrees; in radian mode, trigonometric inputs are interpreted as radians.

Supported functions and syntax

  • Trigonometry: sin(x), cos(x), tan(x), asin(x), acos(x), atan(x).
  • Logarithms: log(x) for base 10 and ln(x) for the natural logarithm.
  • Other functions: sqrt(x), abs(x), exp(x).
  • Constants and operators: pi, e, +, -, *, /, ^ and parentheses.

Scientific calculator examples

  • sqrt(144) = 12.
  • 2^8 = 256.
  • log(1000) = 3.
  • sin(30) = 0.5 in degree mode.
  • ln(e) = 1.

Calculation method and limitations

Expressions are tokenised and evaluated using a restricted mathematical parser; arbitrary JavaScript code is not executed. Results use standard JavaScript floating-point arithmetic, so very large, very small or repeating decimal values may be rounded for display. Tangent is undefined where cosine is zero, and logarithms and square roots require valid real-number domains. For coursework or technical work, verify the expression, angle mode and rounding convention.

Frequently asked questions

Is this a free scientific calculator online?

Yes. The calculator runs in your browser and does not require an account.

What is the difference between degrees and radians?

Degrees divide a full turn into 360 units; radians measure angles using the radius of a circle. Select the mode that matches your problem.

Can I enter an expression with brackets?

Yes. Use parentheses to group terms, for example 2*(3+4). Multiplication must be entered explicitly with an asterisk.

Does it show step-by-step working?

This version provides the evaluated result and supported function syntax; it does not generate a full symbolic derivation.

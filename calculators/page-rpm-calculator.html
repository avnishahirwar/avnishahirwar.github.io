What is Page RPM?

Page RPM means page revenue per thousand page views. It expresses estimated earnings relative to the number of page views, making it easier to compare performance across pages, periods or websites. It is a reporting metric, not a guaranteed rate or a promise of future income.

Page RPM formula

Page RPM = (Estimated earnings ÷ Page views) × 1,000

For example, if a site records ₹600 in estimated earnings from 30,000 page views, its Page RPM is (₹600 ÷ 30,000) × 1,000 = ₹20.

How to use this calculator

  1. Choose whether you want to calculate Page RPM, estimate revenue or estimate required page views.
  2. Select the currency used for your earnings figures. The selector changes the display only; it does not convert exchange rates.
  3. Enter your estimated earnings and page views, or the Page RPM and target value required for the selected calculation.
  4. Select Calculate to see the result and the formula used.

Understand the result

A higher Page RPM means more estimated revenue per thousand page views for the period and reporting basis used. RPM can vary with audience location, content topic, advertiser demand, seasonality, ad placement, consent choices and traffic quality. Compare like-for-like date ranges and use your own verified reporting data.

Page RPM vs. Ad RPM

Page RPM uses page views as its denominator. Ad RPM uses ad impressions instead. A page can contain more than one ad impression, so these metrics are not interchangeable. Use the metric that matches the denominator in the source report.

Limitations

This tool performs arithmetic using values you provide. It does not connect to Google AdSense or another advertising account, retrieve analytics, verify earnings, predict future results or recommend ad placements. Actual revenue can differ from an estimate. Review the reporting definitions and policies of your advertising provider.

Worked examples

Example 1 — calculate Page RPM: A publisher records ₹600 in estimated earnings and 30,000 page views for the same reporting period. Divide ₹600 by 30,000 and multiply by 1,000. The result is ₹20 Page RPM.

Example 2 — estimate revenue: If a site receives 80,000 page views and uses an assumed Page RPM of ₹35, the estimate is (80,000 ÷ 1,000) × ₹35 = ₹2,800. This is a scenario calculation, not a forecast.

Example 3 — estimate required traffic: For a target of ₹5,000 at an assumed Page RPM of ₹25, the arithmetic is (₹5,000 ÷ ₹25) × 1,000 = 200,000 page views. Actual traffic and earnings may not follow the assumption.

Choose consistent reporting data

Use earnings and page views from the same property, date range, time zone and reporting currency. Do not divide a monthly earnings figure by a daily page-view figure. If one report uses sessions and another uses page views, use the page-view figure for Page RPM. Sessions, users, ad impressions and page views are different measurements.

How to compare periods fairly

Compare equivalent periods and check whether the traffic mix changed. Audience geography, device mix, content subject, seasonality, advertiser demand, consent rates, ad availability and page layout can all affect reported results. A change in Page RPM alone does not identify the cause. Review the underlying traffic and advertising reports before making a decision.

Calculation assumptions and methodology

  • The calculator treats the earnings amount and Page RPM as values in the selected display currency; it does not perform foreign-exchange conversion.
  • Page RPM is calculated from estimated earnings divided by page views, multiplied by 1,000.
  • Revenue estimates use page views divided by 1,000, multiplied by the assumed Page RPM.
  • Required page views use target earnings divided by a positive assumed Page RPM, multiplied by 1,000; the displayed traffic requirement is rounded up to a whole page view.
  • Inputs are validated in the browser. Earnings and target values may be zero where the selected calculation permits it; page views must be a positive whole number.
  • No account data is fetched, stored on a Friendly Calculator server or sent to an advertising provider by this tool.

When this estimate should not be used

Do not treat an estimated Page RPM as a guaranteed earning rate, a valuation of a website, or a promise of future advertising income. This calculator does not assess invalid traffic, policy compliance, ad serving eligibility, fill rate or the quality of a site's audience. It cannot determine whether a particular ad placement or monetisation strategy complies with an advertising provider's rules.

Frequently asked questions

How is Page RPM calculated?

Divide estimated earnings by page views, then multiply by 1,000.

Can Page RPM be calculated when earnings are zero?

Yes. If page views are greater than zero and earnings are zero, Page RPM is zero.

Does this calculator connect to my AdSense account?

No. Enter values manually. The calculator runs in your browser and does not request account access.

Does changing the currency convert my earnings?

No. Currency selection changes the symbol and code shown in the result. Convert source values separately using an exchange rate appropriate to your reporting date.

Is Page RPM the same as Ad RPM?

No. Page RPM is based on page views; Ad RPM is based on ad impressions.

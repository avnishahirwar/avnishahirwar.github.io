Projector Calculator

The projector calculator finds the optimum viewing distance and throw distance for a specific projection size.

Enter values

How it works

This calculator evaluates the displayed equation variants locally in your browser. Enter the known values; results are shown for equations whose required inputs are available.

Check units, assumptions and professional guidance before using results for medical, financial, legal, engineering or safety-critical decisions.

Formulas used by this calculator

The Projector Calculator works with 21 quantities and 37 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • Aspect ratio (aspect_ratio) = width/height
  • Height (height) = width/aspect_ratio
  • Width (width) = aspect_ratio × height
  • Min throw distance (min_throw_distance) = min_throw_ratio × width
  • Max throw distance (max_throw_distance) = max_throw_ratio × width
  • Min throw ratio (min_throw_ratio) = min_throw_distance/width
  • Max throw ratio (max_throw_ratio) = max_throw_distance/width
  • Min viewing distance (min_viewing_distance) = (1/2) × width/tan(122173/200000)

29 further rearrangements of the same relations let you solve for other quantities.

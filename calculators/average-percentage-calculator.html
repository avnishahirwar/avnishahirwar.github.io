Average Percentage Calculator

Enter four percentage values to calculate their arithmetic average.

Use the calculator

How to use this calculator

Enter the four percentage values. Each value has equal weight in this calculation.

Formula and methodology

Average percentage = (sum of the entered percentage values) ÷ 4.

Worked example

The average of 70%, 80%, 90% and 60% is 75%.

Important limitations

Results follow the mathematical definitions and assumptions stated on this page. Check the displayed inputs and rounding before using results in coursework or technical work.

Frequently asked questions

Is this a weighted average?

No. Each of the four entered percentages has equal weight.

Can a percentage exceed 100%?

Yes. Enter values above 100% when the rate or index being measured can exceed 100%.

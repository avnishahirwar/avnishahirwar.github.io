Formulas used by this calculator

The Resistor Wattage Calculator works with 29 quantities and 23 relations between them. Enter the values you know, leave the one you want to find blank, and press Calculate. Blank fields are never treated as zero. Each formula below is solved for one quantity.

  • I current (i_current) = power/voltage
  • Voltage (voltage) = power/i_current
  • Resistance (resistance) = voltage/i_current
  • Power (power) = i_current × voltage
  • S equivalent Resistance (S_equivalentResistance) = r1 + r10 + r2 + r3 + r4 + r5 + r6 + r7 + r8 + r9
  • R10 (r10) = S_equivalentResistance - r1 - r2 - r3 - r4 - r5 - r6 - r7 - r8 - r9
  • r7 (r7) = S_equivalentResistance - r1 - r10 - r2 - r3 - r4 - r5 - r6 - r8 - r9
  • r9 (r9) = S_equivalentResistance - r1 - r10 - r2 - r3 - r4 - r5 - r6 - r7 - r8

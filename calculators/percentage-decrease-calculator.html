Percentage Decrease Calculator

Enter the starting value and the percentage reduction to see the amount removed and the value remaining.

Use the Percentage Decrease Calculator

How to use this calculator

Enter the original value and a decrease rate from 0% to 100%, then select Calculate.

Formula

Decrease = Original value × Decrease rate ÷ 100. New value = Original value − Decrease.

Example and interpretation

A 15% decrease on 100 removes 15, leaving a new value of 85.

Important limitations

This tool performs the mathematical operation described above using only the values entered. Check units, data quality and the selected interpretation before relying on a result.

Frequently asked questions

Can a decrease be more than 100%?

This calculator limits a decrease to 100% so the resulting value does not become negative.

How is the remaining value calculated?

Subtract the decrease amount from the original value.

Privacy Policy

Last updated: 9 November 2026

This policy explains how AVNISH AI handles information when you visit this website, submit an enquiry or use an approved API integration.

Calculator data

Calculator inputs and calculations on the main website are processed in your browser. These browser calculators are not designed to transmit the values you enter to AVNISH AI servers.

Contact, advertising and API enquiry forms

When you submit a form, the information you provide is transmitted securely to our backend and stored so that we can review and respond to your enquiry. Depending on the form, this may include your name, email address, company or project name, optional phone or budget details, enquiry type and message. Enquiries are accessible only to authorised administrators.

We use a hashed connection identifier to help prevent repeated automated submissions. It is not stored as a plain IP address. Older rate-limit entries are cleaned during subsequent form submissions, targeting a 48-hour window.

Please do not include passwords, OTPs, API secrets, payment-card details, government identity numbers or other sensitive information in an enquiry.

API credentials and usage

For approved API access, AVNISH AI stores a cryptographic hash and short prefix of each API key, not the original secret key. The original key is shown only once when created. API usage records may include the key identifier, calculator endpoint, response status and timestamp; request payloads are not stored for usage analytics. Usage records are routinely cleaned when API requests occur, targeting a 90-day retention window.

API keys are intended for server-side use. Keep them confidential and contact us promptly if a key may have been exposed.

Hosting and data processors

The website is hosted through Vercel. Enquiry storage, authentication and API processing use Supabase. The Supabase project is configured in the ap-northeast-2 region (Seoul, South Korea). These providers process information to operate the service under their own terms and privacy policies.

Advertising and cookies

This website includes Google AdSense publisher code. Ads will be served only if Google enables them for this website and publisher account. If advertising is served, Google and its partners may use cookies or similar technologies for ad delivery, measurement and personalisation, subject to Google's policies and the choices available in your region. The presence of code does not confirm approval or active ad serving.

Review Google's advertising technologies and Google's Privacy Policy.

Retention and privacy requests

Enquiry records are retained while needed to respond, maintain business records, prevent abuse or meet applicable obligations. You may request access, correction or deletion of an enquiry by emailing avnishahirwar415@gmail.com. We may need to retain limited records where required for security, legal or legitimate operational reasons.

External links

Links to Instagram, Facebook, LinkedIn and other external websites are governed by those providers' own privacy practices. AVNISH AI does not control their services.

Changes

This policy may be updated when website features or legal requirements change. The latest version will be published here.
